# Scrape Farm — UI preview

A static, click-through preview of two proposed redesigns of the Scrape Farm control plane.

- Version 1: https://mekko-digital.github.io/scrape-farm-demo/v1/scrape-farm/login/
- Version 2: https://mekko-digital.github.io/scrape-farm-demo/v2/scrape-farm/login/

Sign in with the password `preview`. Everything shown is sample data; nothing is saved and nothing
connects to LinkedIn, the scraper or a CRM. This repository holds only the built preview files —
the application's source lives in a private repository.
